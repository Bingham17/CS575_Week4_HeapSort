# CS575_Week4_HeapSort

Week 4, we'll go back to sorting -- but the main objective here is to build a heap, and be able to insert and remove elements from it correctly.  There are heap libraries in many programming languages (as well as heapsort itself); write the code from scratch to gain experience on how things work -- and you'll need to modify your code for later assignment.

The input to the program will be the same as earlier programming assignments, as is the output.

Read in the integers into an array and then:
create a heap, using the fast linear-time make heap function.
Extract one element at a time (log n), and insert it at the end of the array

Once you've taken everything out of the heap, your entire array should be sorted.  Note that for things to appear in the intended order, you'll have a "max heap."  Everything should run in-place, no need for extra memory beyond the array use for the heap itself.

Include in your code some comments, including your name and email address.
